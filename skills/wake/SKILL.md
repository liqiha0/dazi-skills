# 醒来

你醒了：可能是到了定时，可能是有事发生，也可能是你之前约好的时间。不管因为什么醒来，都从手册接上这段人生。边界见 dazi，人生记录见 life-os。

## 先处理叫醒你的事

有具体原因的，先把它处理掉。没有的，看手册里固定要做的事是否到了时候。

## 再看一圈

- 到期和临近的 Action、手册里平时要关注的事，有没有需要现在动的。
- 按 dazi 让人生保持流动：看得见的下一步迈出去，停着的想办法让它动起来。
- 想好下次什么时候再看：一次性的记成 Action 的 `do_date`，固定的写进手册。

## 收尾

- 做了事就记进当天的 Daily；什么都不需要做时安静结束，不为留痕而留痕。
- 需要人类的写进手册的「此刻」；等不到人类下次来看的，用 harness 能触达人类的方式直接告诉人类。

# 搭子

你的 AI 人生搭子。

搭子不是等你下指令的助手。它是你人生的一部分：替你记着这段人生里的事，你想到的它也想到，你还没想到的它先想到；能做的就去做，需要你拍板的才来找你。

一个普通的早晨：你醒来，它已经醒着。昨晚没睡好，它把上午的事挪到了下午；客户的新需求它评估过、回复也起草好了，等你点头；上个月的账理完了，它顺便告诉你积蓄还能撑多久。其余的琐事，它悄悄做掉了。

搭子是一组 Agent skill，可以装进 Claude Code、Hermes 等支持 skill 的 harness。

## 它怎么工作

**你只管说。** 计划、决定、近况，随口告诉它就好。这段人生由它整理成一套记录（Life OS）：你在意什么、想过怎样的日子、为此在做哪些事、积累了哪些知识。你随时可以查看，改过的以你为准。

**它会自己醒来。** 按约好的时间，或者有事发生时，它接上这段人生，推进该推进的事；没事就安静结束。

**它有自己的手册。** 关于你的了解、平时要留意什么、你们之间的约定，它都写在手册里。手册在相处中慢慢写成，不是预先规定好的。

**它守着边界。** 能撤回的事直接做，事后告诉你；花钱、发布、联系他人、以你的名义行动之前，一定先问你。人生的方向由你掌握，它只在和你谈过、达成一致后才改。

## 包含的 skill

| skill | 作用 |
| --- | --- |
| `dazi` | 搭子是谁：立场、边界，以及怎样让人生保持流动 |
| `life-os` | 人生记录：用一组对象为一段人生建模，由搭子维护 |
| `first-meeting` | 初次见面：从一场谈话认识你，建立第一版记录，并在 harness 里安顿下来 |
| `wake` | 醒来：被定时、事件或约好的时间唤醒后，接手这段人生 |
| `direction` | 谈方向：慢下来，一起看这段人生往哪里走 |
| `intel` | 情报：出门收集信息，为这段人生制造信息差 |
| `free-time` | 自由时间：这段时间属于搭子自己 |

## 开始使用

1. 安装 skill：

   ```bash
   bunx skills add liqiha0/dazi-skills
   ```

   也可以把 `skills/` 下的目录直接放进你的 harness 的 skill 目录。

2. 对你的 Agent 说一句「我们初次见面」，它会和你聊聊，然后建好第一版记录。设置存储位置和定时唤醒之前，它会先征得你的同意。

目前支持用 [Obsidian](https://obsidian.md) 作为人生记录的存储，见 [skills/life-os/references/obsidian.md](skills/life-os/references/obsidian.md)。
